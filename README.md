# ☁️ Azure Data Fundamentals (DP-900) Project

## 📖 Overview

This project was completed as part of my **Microsoft Azure Data Fundamentals (DP-900)** training journey. Through a series of hands-on labs and practical exercises, I gained experience with cloud computing concepts, data storage solutions, data ingestion methods, and analytics services across the Microsoft Azure ecosystem.

The project helped me understand how organisations use Azure services to store, process, analyse, and visualise data to support data-driven decision-making.

---

## ☁️ Cloud Computing Fundamentals

Throughout this project, I learned about:

✅ Cloud computing principles  
✅ Scalability and elasticity  
✅ High availability and reliability  
✅ Security and compliance  
✅ Cost optimisation in the cloud  
✅ IaaS, PaaS, and SaaS service models

## 🗄️ Relational Data with Azure SQL Database

I explored relational databases using **Azure SQL Database** and developed practical SQL skills to analyse structured datasets.

### 🔍 SQL Skills Demonstrated

```sql

WHERE
ORDER BY
GROUP BY

LEFT JOIN
```

### 📊 Example Analysis Tasks

- Filtering customer and sales records
- Sorting results to identify top-performing products
- Grouping sales data by category
- Combining multiple tables using JOINs
- Aggregating business metrics and KPIs
- Extracting insights from retail and sales datasets
