# Azure Data Fundamentals (DP-900) Project

## Overview
This project was completed as part of the **Microsoft Azure Data Fundamentals (DP-900)** training course. The aim was to develop a practical understanding of cloud computing, data storage, data processing, and analytics across the Azure ecosystem. Throughout the project, I explored how different Azure services support relational, non-relational, and analytical workloads while applying fundamental data analysis skills to real-world datasets. 

## Key Learning Areas

### ☁️ Cloud Computing Fundamentals
- Explored cloud concepts, including scalability, availability, security, and cost efficiency.
- Gained an understanding of the different cloud service models:
  - Infrastructure as a Service (IaaS)
  - Platform as a Service (PaaS)
  - Software as a Service (SaaS)
- Learned how organisations use Azure to modernise data solutions and support business operations. 

### 🗄️ Relational Data with Azure SQL Database
Worked with **Azure SQL Database** to store and query structured data using SQL.

Key SQL skills demonstrated:
```sql
SELECT
WHERE
ORDER BY
GROUP BY
JOIN
```

These queries were used to:
- Filter and retrieve relevant records
- Sort datasets for analysis
- Aggregate sales and performance metrics
- Combine data from multiple tables
- Generate insights from business and retail-style datasets

The project helped strengthen my understanding of relational database concepts, tables, relationships, and data modelling. 

### 📦 Non-Relational Data with Azure Storage and Cosmos DB
Explored non-relational data solutions including:
- Azure Storage Accounts
- Azure Blob Storage
- Azure Cosmos DB

Key concepts covered:
- Storing unstructured and semi-structured data
- JSON document storage
- Flexible schema design
- Scalable cloud-based storage solutions

This provided practical experience in selecting the appropriate storage solution depending on data type and business requirements.

### 📊 Analytical Workloads with Microsoft Fabric
Used **Microsoft Fabric Lakehouse** to explore large-scale analytics and reporting workflows.

Activities included:
- Loading and analysing data within a Lakehouse environment
- Running queries to investigate datasets
- Exploring real-time analytics capabilities
- Creating visualisations and reports using Power BI

This demonstrated how modern analytics platforms combine data engineering, storage, and reporting within a unified solution. 

### 🔄 Data Ingestion and Integration
Gained experience with data ingestion concepts and methods including:
- Eventstreams for handling real-time data
- Data import from files and external sources
- Cloud-based data pipelines
- Data movement and preparation processes

These activities highlighted how data can be collected, transformed, and prepared for reporting and analytics workloads. 

## Skills Developed

This project strengthened my understanding of Azure's data platform and how different services work together to support data-driven decision-making.
